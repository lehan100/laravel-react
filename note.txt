git status: Kiểm tra trạng thái hiện tại (file nào đã sửa, file nào đã đưa vào staging).
git add <file> hoặc git add .: Đưa các thay đổi vào vùng chờ (staging area).
git commit -m "message": Lưu lại ảnh chụp (snapshot) của các thay đổi vào kho lưu trữ cục bộ.
git push origin <branch>: Đẩy các commit từ máy cá nhân lên server (GitHub, GitLab...).
git pull: Cập nhật mã nguồn mới nhất từ server về máy và tự động merge. 
-----------
feat: Thêm một tính năng mới cho người dùng.
fix: Sửa một lỗi (bug).
docs: Thay đổi về tài liệu (như file README).
style: Thay đổi về định dạng code (khoảng trắng, dấu phẩy...) mà không làm thay đổi logic code.
refactor: Tái cấu trúc mã nguồn (không sửa lỗi cũng không thêm tính năng).
perf: Cải thiện hiệu suất.
test: Thêm hoặc sửa các bài kiểm tra (unit tests).
chore: Các thay đổi nhỏ nhặt về quá trình build hoặc công cụ hỗ trợ (như cập nhật thư viện).
-----------
git branch: Liệt kê tất cả các nhánh hiện có.
git checkout -b <tên-nhánh>: Tạo một nhánh mới và chuyển sang nhánh đó ngay lập tức.
git switch <tên-nhánh>: Chuyển đổi giữa các nhánh một cách an toàn.
git merge <tên-nhánh>: Gộp các thay đổi từ nhánh khác vào nhánh hiện

Setup domain + https
1. Download mkcert-v1.4.4-windows-amd64.exe
- https://github.com/filosottile/mkcert/releases
- PowerShell: cd C:\Users\Admin\Downloads
- PowerShell: .\mkcert-v1.4.4-windows-amd64.exe -install
- PowerShell: .\mkcert-v1.4.4-windows-amd64.exe domain.com
2. update hosts
- C:\Windows\System32\drivers\etc\hosts
- Add: 127.0.0.1 domain.com
3. update compose.yaml
  ports:
     - '${VITE_PORT:-5173}:${VITE_PORT:-5173}'
   nginx-proxy:
        image: 'jc21/nginx-proxy-manager:latest'
        restart: unless-stopped
        ports:
            - '80:80'  
            - '81:81'  
            - '443:443' # HTTPS
        volumes:
            - './docker/nginx/data:/data'
            - './docker/nginx/letsencrypt:/etc/letsencrypt'
            - './certs:/etc/nginx/certs' 
        networks:
            - sail
        depends_on:
            - laravel.test
4. .env
 - APP_URL=https://domain.com
5. goto url http://localhost:81/
    5.1. Add mkcert certificate to Nginx Proxy Manager:
        - Go to SSL Certificates -> Add SSL Certificate -> Custom.
        - Name it domain-ssl.
        - Certificate Key: Select the domain.com-key.pem file.
        - Certificate: Select the domain.com.pem file.
        - Click Save.
5.2. Point the domain domain.com to Laravel:
    - Go to Hosts -> Proxy Hosts -> Add Proxy Host.
    - Domain Names: Enter domain.com.
    - Scheme: Select http.
    - Forward Hostname / IP: Enter laravel.test.
    - Forward Port: Enter 80.
    - Go to the SSL tab: Select the domain-ssl certificate you just created and check Force SSL.
    - Click Save.
